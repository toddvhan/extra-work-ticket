How it works

  1. Write the scope in one line a stranger would understand. Fill line items. Set markup in Excel cell B24 (default 20%).
  2. Put a valid-until date. State what the owner supplies and what extra work is a separate ticket.
  3. Print two copies. Client signs if they accept the price for that scope. Attach your actual contract if you use one.

FAQ

Is a signed quote a contract?

It is a price for a written scope. Attach your contract if you use one. Extra work still needs a separate ticket — that is a different kit.

Can I hide the markup?

Excel shows it. On the print PDF you can leave the markup % blank and write only the total. Do not add a surprise percentage later.

Excel or Google Sheets?

Built for Microsoft Excel. Google Sheets will open the files; some formatting may shift. No macros.
